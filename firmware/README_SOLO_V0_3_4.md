# Enduro Solo V0.3.4

Versión para Arduino ESP32 3.3.10 e iOS.

- Instalar `Enduro_Solo_BLE_Keyboard_V036.zip`.
- Abrir `ENDURO_SOLO_V0_3_4/ENDURO_SOLO_V0_3_4.ino`.
- Placa: `ESP32C3 Dev Module`.
- Pulsación breve: `Ctrl+Alt+Shift+T` (vuelta sin escribir texto).
- Pulsación larga: orden `Eject` para mostrar u ocultar el teclado de iOS.
- Batería: combinaciones privadas en pasos de 10%.
